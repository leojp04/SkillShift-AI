# SkillShift AI

Plataforma de requalificação profissional com IA.  
**Slogan:** “Reinvente seu futuro antes que ele te substitua.”

## 📦 Tecnologias
- React + Vite + TypeScript
- TailwindCSS
- React Router
- Consumo de API (Render / Java) ou mock

## ▶️ Como rodar
```bash
npm install
cp .env.example .env
npm run dev
```
